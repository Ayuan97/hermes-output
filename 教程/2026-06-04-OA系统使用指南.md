# OA 系统使用指南

## 基本信息

- **地址**: `http://182.44.10.210:9527`
- **名称**: 一个理念网络科技 OA
- **登录方式**: 飞书账号 OAuth 授权（点击「飞书登录」按钮）

## 系统结构

### 左侧导航

| 分类 | 功能 | 说明 |
|------|------|------|
| 常用功能 | 工作台 | 总览待办/进行中/已完成统计 |
| 常用功能 | 我的任务 | 个人任务列表 |
| 常用功能 | 思维导图 | 内置思维导图工具 |
| 常用功能 | 活动日志 | 操作记录 |
| 办公功能 | 项目管理 | 项目/议题/任务/缺陷管理 |
| 系统管理 | 权限管理 | 角色与权限配置 |

### 工作台页面

顶部显示 6 个状态统计卡片：
- 待规划、待处理、进行中、评审中、验证中、已完成

下方 4 个 Tab：
- **我的议题** — 按状态筛选（全部/待处理/进行中/评审中/验证中）
- **我的任务** — 按状态筛选（进行中/待办/测试中/已完成）
- **待我审查** — 需要我审查的内容
- **最近浏览** — 最近看过的议题/任务

### 项目管理页面

进入项目后有以下模块：
- **仪表盘** — 项目概览
- **议题** — 主要工作项（支持迭代管理）
- **任务** — 子任务管理
- **缺陷** — Bug 追踪
- **路线图** — 版本规划
- **质量** — 质量指标

## 鲸量引擎项目

### 迭代管理

- 项目使用「项目通用迭代」议题，每 3 天一轮
- 标题格式：`项目通用迭代-迭代日期MMDD-MMDD`
- 迭代状态：打开 → 已关闭
- 预计花费时间：通常 3.0 天（72 小时）

### 日报填写

- **位置**: 当前进行中的迭代议题评论区
- **格式**: Markdown 评论，列出当日工作内容
- **参与者角色**: 执行者、审查者、关注者
- **仓库绑定**: 可绑定 Git 仓库，提交自动出现在评论区

### 议题详情页结构

- **左侧**: 时间线评论区（含迭代目标、每日工作汇报）
- **右侧**: 
  - 任务池（快速添加任务）
  - 详细信息（状态、创建时间、创建者、项目、预计时间）
  - 子议题
  - 参与者（执行者/审查者/关注者）
  - 仓库绑定
  - 关联任务
  - 时间节点

## 常用操作

### 查看当前迭代
1. 进入「项目管理」→ 鲸量引擎
2. 找到标题含最近日期的「项目通用迭代」议题
3. 点击进入详情页查看评论区

### 填写日报
1. 进入当前迭代议题
2. 在评论区输入框（`textarea.w-md-editor-text-input`）写入汇总
3. 点击「发布评论」

### 任务池
- 在迭代详情页右侧的「任务池」面板添加任务
- 任何人可以随时认领任务

## 技术备注

- 前端使用 Vue.js（SPA，`#root` 入口）
- 评论编辑器使用 `w-md-editor`（Markdown 编辑器）
- Tab 切换使用 Radix UI 组件
- 后端 API 地址：`http://182.44.10.210:9527`
