## 🚀 爆款项目 TOP 5

### 1. [OpenCut-app/OpenCut](https://github.com/OpenCut-app/OpenCut) — ⭐+4,276/天 | TypeScript
**开源版剪映/CapCut。** 基于 Web 的专业视频编辑器，目标是做开源的 CapCut 替代品。

**为什么火：** 视频创作者苦 CapCut 久矣——闭源、数据上传、功能限制。这个项目直接对标 CapCut 核心功能，用 TypeScript 构建，浏览器端运行，不需要安装。日增 4000+ 星说明需求巨大。

**对主子的价值：** 值得关注+收藏。如果后续功能稳定，可以替代 CapCut 做视频剪辑，数据完全自己掌控。也是很好的视频选题——"开源版剪映来了"。

### 2. [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) — ⭐+1,851/天 | Python

**为什么火：** 解决了 AI 编码助手的核心痛点——上下文理解不够深。把代码、数据库 schema、基础设施全部构建成一张知识图谱，AI 就能更准确地理解项目全貌。思路非常新颖。

**对主子的价值：** 值得 clone 下来试试，特别是如果主子有大项目需要 AI 辅助重构或理解。也可以做视频——"让 AI 真正看懂你的代码"。
