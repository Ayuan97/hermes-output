# Hermes 技能社区调研报告（2026-05-28）

## 背景

今天纠正了一个理解偏差：主子说的「Hermes 社区」主要指 **Hermes 技能社区 / 技能市场**，不是 GitHub 代码贡献社区或 Discord 讨论区。

## 技能来源结构

- **内置技能**：本机原来约 90 个，可靠性最高，覆盖软件开发、GitHub、研究、生产力、Apple、DevOps 等方向。
- **官方可选技能**：Nous 官方维护，约 84 个，信任等级最高，优先评估。
- **skills.sh 社区技能**：安装量信息明显，但质量参差不齐，很多依赖额外服务。
- **browse-sh / ClawHub / LobeHub 等来源**：数量多，但需要逐个审查，不适合盲装。

## 本机当时技能状态

- 总启用：101 个
- 内置：90 个
- 本地自建：10 个
- 社区安装：1 个
- 唯一社区安装技能：`parallel-deep-research`

`parallel-deep-research` 需要付费 Parallel API 和 `parallel-cli`，不符合主子「拿来就能用、不依赖额外付费服务」的偏好。

## 抽样技能结论

### 代理浏览器技能（`agent-browser`）

- 安装量约 315,934。
- 用途：浏览器自动化、填表、点击、截图、抓取、网站测试、Electron 应用操作。
- 问题：需要额外安装并运行自己的命令行工具。
- 判断：可关注，但不急着安装；本机已有浏览器和桌面控制能力。

### 复用本地浏览器技能（`use-my-browser`）

- 安装量约 168,338。
- 价值主要在方法论：判断何时必须用真实浏览器、何时静态抓取即可、不要滥用浏览器、任务后沉淀站点经验。
- 判断：思路值得吸收，但不一定需要安装。

### 并行深度研究技能（`parallel-deep-research`）

- 安装量约 8,843。
- 依赖付费 Parallel API 和额外 CLI。
- 判断：不推荐保留。

### Firecrawl 深度研究类技能

- 安装量约 5,407。
- 依赖 Firecrawl API，通常需要额外账号或付费额度。
- 判断：不推荐优先使用。

### Web 研究流程类技能

- 代表：`langchain-ai/deepagents/web-research`，安装量约 2,757。
- 价值：先建研究计划、拆分子任务、并行子代理、最终汇总报告。
- 判断：流程有价值，但本机已有 `delegate_task`、浏览器、网页和历史会话搜索能力，适合吸收流程而不是直接安装。

### GitHub 类技能

- 社区里 `github-issues`、`gh-cli` 等安装量高。
- 本机已有内置 GitHub 技能：鉴权、议题、PR、代码审查、仓库管理。
- 判断：不用重复安装。

## 筛选规则

1. **优先官方可选技能**：官方维护、风险低、适配 Hermes。
2. **优先无外部服务依赖的技能**：流程型、提示词型、规范型、能直接用 Hermes 已有工具完成。
3. **社区高安装量只作为线索**：安装量高不代表适合本机环境。
4. **谨慎避开外部付费依赖**：Parallel、Firecrawl、Browserbase、Vercel Sandbox 等。
5. **不重复安装已有能力**：和本机内置技能重复的社区技能一般不装。
6. **警惕安全扫描异常**：例如凭据暴露、可疑脚本、说明过短但权限要求高。

## 最终建议

对主子最有价值的不是堆技能数量，而是：

- 保留核心内置技能；
- 学习官方可选技能；
- 社区技能只吸收成熟流程；
- 本机常用工作流沉淀成本地技能；
- 对依赖额外付费 API / CLI 的技能默认谨慎。
