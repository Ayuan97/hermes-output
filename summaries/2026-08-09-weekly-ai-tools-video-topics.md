## 选题 1：AnyDoc —— Firecrawl 出品的万能文档转 Markdown 工具

- **工具/项目**：[firecrawl/anydoc](https://github.com/firecrawl/anydoc)
- **Star**：12,718 ⭐
- **热门原因**：
  - Firecrawl 官方出品，品质保证
  - 用 Rust 写的，性能极强
  - 支持 Word、PPT、Excel、PDF、EPUB、CSV 等几乎所有常见文档格式
  - 一键转换为干净的 Markdown，对 AI 处理非常友好
  - 提供 Node.js 和 Python 绑定，开发者友好
- **视频切入角度**：
  - "告别手动复制粘贴！这个工具能把所有文档一键转成 Markdown"
  - "AI 时代最被低估的工具：AnyDoc 文档转换器实测"
  - "给 AI 喂数据的最佳姿势：AnyDoc 保姆级教程"
- **目标观众**：内容创作者、研究人员、AI 开发者、效率工具爱好者
- **可演示步骤**：
  1. 安装 AnyDoc（npm 或 pip）
  2. 准备各种格式的测试文档（PDF、Word、PPT、Excel）
  3. 批量转换文档为 Markdown
  4. 展示转换效果（表格、图片、格式保留情况）
  5. 接入 AI 工作流：转换后直接喂给 ChatGPT/Claude
  6. 对比其他工具（如 markitdown、pypandoc）
- **风险/坑点**：
  - 需要安装 Rust 环境（如果用源码编译）
  - 复杂排版的 PDF 转换效果可能不完美
  - 大文件处理速度待测试
