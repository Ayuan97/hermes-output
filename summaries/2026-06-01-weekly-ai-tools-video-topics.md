### 选题 1：小红书图文卡片自动生成——用 AI Agent 做爆款排版

**工具/项目**：[guizang-social-card-skill](https://github.com/op7418/guizang-social-card-skill)  
**本周热度**：⭐ 2046（本周新项目，仅 5 天）  
**热门原因**：小红书/公众号图文是目前国内流量最大的内容形式之一，该项目把一个 AI Agent 技能（用于 Claude Code/Codex）变成"小红书排版神器"，内置电子杂志风和瑞士网格风两套视觉系统，28 种布局，安装即用。  
**视频切入角度**：
- "给我一篇文章，3 秒出一套小红书图文"——用 Claude Code 演示全流程
- 对比：手工做一套小红书图文 vs AI 一键生成
- 适合做"创意效率工具"系列  
**目标观众**：自媒体运营、小红书博主、公众号编辑、设计师、AI 工具爱好者  
**可演示步骤**：
1. 安装 npx skills add 该 skill
2. 准备一篇文案
3. 对 Agent 说指令："帮我做一套瑞士风小红书图文，5 张，IKB 蓝"
4. 展示生成的 HTML → PNG 效果
**风险/坑点**：需要 Claude Code 或 Codex 环境（付费）；依赖 HTML → PNG 截图质量；中文排版可能因为字体缺失而错位  
**推荐指数**：⭐⭐⭐⭐⭐

### 选题 2：自部署 ChatGPT/Claude 平替——Odysseus 本地 AI 工作台

**工具/项目**：[Odysseus](https://github.com/pewdiepie-archdaemon/odysseus)  
**本周热度**：⭐ 7803（仅发布 1 天）  
**热门原因**：一夜爆星的项目。自称"可在自己硬件上跑的自部署版 ChatGPT 体验"，集成 Chat、Agent、Deep Research、邮件、日历、备忘录等功能，本地优先、隐私优先。  
**视频切入角度**：
- "在自己的电脑上搭一个完全离线的 ChatGPT"——Docker 部署全记录
- 对比使用效果：Odysseus + 本地模型 vs ChatGPT Plus
- 适合"从 0 到 1 部署"教程系列  
**目标观众**：自部署爱好者、关注数据隐私的用户、开发者、AI 玩家  
**可演示步骤**：
1. git clone 项目
2. Docker Compose 启动
3. 配置 Ollama/本地模型或 API
4. 展示聊天、Deep Research、Agent 功能
**风险/坑点**：需要一定硬件资源（推荐 16GB+ VRAM 或依赖 API）；项目太新可能有稳定性问题；需要 Docker 基础  
**推荐指数**：⭐⭐⭐⭐⭐

### 选题 3：AI 自动做 PPT——适合中国宝宝的 PPT Builder Skill

**工具/项目**：[GordenPPTSkill](https://github.com/GordenSun/GordenPPTSkill)  
**本周热度**：⭐ 828  
**热门原因**：号称"最强原生 PPT Skill，更适合中国宝宝"，内置 17 套中文 PPTX 模板，兼容 DeepSeek/Claude/GPT/小米 Mimo 等所有模型，还能自动更新技能。非商业使用免费。  
**视频切入角度**：
- "一句话让 AI 给你做 PPT，比手动快 10 倍"——从文案到 PPT 的全流程演示
- 对比：做同样一页 PPT，手动 vs AI 时间对比
- 适合"职场效率工具"系列  
**目标观众**：上班族、产品经理、学生、需要经常做 PPT 的人群  
**可演示步骤**：
1. 安装 skill 到 Claude Code/Codex
2. 输入文案/大纲
3. AI 自动选择模板、填充内容
4. 导出 PPTX + 预览图
**风险/坑点**：需要安装 LibreOffice 和 poppler 做预览渲染；模板风格可能被公司合规拒绝；非商业使用限制  
**推荐指数**：⭐⭐⭐⭐⭐

### 选题 4：VibeCode 神器——让你的 AI 不再"失忆"

**工具/项目**：[vibecode-pro-max-kit](https://github.com/withkynam/vibecode-pro-max-kit)  
**本周热度**：⭐ 667  
**热门原因**：AI 编程最头疼的问题之一就是"上下文总是丢"——每次对话 Agent 都忘了之前的代码设计。该项目通过"spec-driven coding harness"解决上下文碎片化问题，宣称 30 秒安装、12 个 Agent、32 个 Skill。  
**视频切入角度**：
- "为什么你的 AI 写代码总是半路失忆？这个工具全解决了"
- 对比：有/无 Vibecode Kit 的 Claude Code 开发体验
- 适合"AI 编程进阶"系列  
**目标观众**：使用 AI 编程的开发者和产品经理、VibeCoding 爱好者  
**可演示步骤**：
1. 展示一个没有 Spec 的 Claude Code 项目——上下文漂移
2. 安装 vibecode-pro-max-kit
3. 写一份 Spec，Agent 按 Spec 持续开发
4. 展示上下文一致性和代码质量提升
**风险/坑点**：工具链锁定的风险；需要了解基本的 Spec 编写方式；目前还是社区项目，长期维护不确定  
**推荐指数**：⭐⭐⭐⭐

### 选题 5：用代码画画——GenClaw 让 AI 像设计师一样创作

**工具/项目**：[GenClaw](https://github.com/yejy53/GenClaw)  
**本周热度**：⭐ 97（学术论文配套，arXiv 2605.30248）  
**热门原因**：来自学术圈的创新——让 AI Agent 先用代码（SVG/HTML/CSS/Python 3D）"画草图"，再调用图像模型渲染。核心思想：先想、再画、最后渲染。解决纯 Prompt 生图"不可控、不能改"的问题。  
**视频切入角度**：
- "AI 生图的新范式：先写代码再渲染，结果完全可控"
- 演示：用 GenClaw 做复杂场景合成、文字排版、精确构图
- 适合"AI + 设计前沿"系列  
**目标观众**：设计师、AI 创作者、技术型创作者、学术爱好者  
**可演示步骤**：
1. 安装 GenClaw
2. 写一份简单需求："画一个人站在山顶，身后有月亮"
3. 观察 Agent 先画 SVG 草图，再调用模型渲染
4. 修改 SVG 代码 → 控制最终效果
**风险/坑点**：项目较新（97 星），处于早期阶段；需要一定的代码理解能力；图像质量取决于底层模型  
**推荐指数**：⭐⭐⭐⭐

### 选题 7：AI Agent 也能操控 WPS Office——harness-anything

**工具/项目**：[harness-anything](https://github.com/yb2460/harness-anything)  
**本周热度**：⭐ 209  
**热门原因**：可以让 AI Agent 通过 COM 自动化控制 WPS Office（Writer、Calc、Impress），实现"AI 帮你写文档、做表格、排报告"。国内 WPS 用户量极大，这个工具直接解决了 Agent 能操控办公软件的问题。  
**视频切入角度**：
- "让 AI Agent 帮你用 WPS 写周报、做表格、排报告"
- 演示：用 Claude Code 调用 WPS Writer 写文档、WPS Calc 做数据分析
- 适合"上班族 AI 实战"系列  
**目标观众**：WPS 用户、上班族、行政、财务、需要大量 Office 输出的人群  
**可演示步骤**：
1. 安装 Python 依赖和 COM 绑定
2. 让 Agent 打开 WPS Writer 创建文档
3. 让 Agent 在 WPS Calc 中做数据透视表
4. 展示完整的"说话→出文档"流程
**风险/坑点**：仅支持 Windows（COM 自动化），macOS 用户不行；WPS 需要安装专业版；中文识别可能需要注意编码  
**推荐指数**：⭐⭐⭐⭐

### 选题 8：Duel Agents——让两个 AI 互相辩论你来做裁判

**工具/项目**：[Duel-Agents](https://github.com/2aronS/Duel-Agents)  
**本周热度**：⭐ 573  
**热门原因**：让两个 AI Agent 就一个问题展开辩论（CLI/SDK/IDE 插件），用户做裁判来评判谁更合理。对抗式生成既能提升结果质量，又有娱乐性——非常适合视频内容。  
**视频切入角度**：
- "让 ChatGPT 和 Claude 当面吵架，我当裁判——结果太精彩了"
- 演示：让两个 Agent 辩论"AI 会不会取代程序员"等热门话题
- 适合"AI 娱乐 + 评测"系列  
**目标观众**：AI 爱好者、技术吃瓜群众、开发者、想了解 AI 能力差异的人  
**可演示步骤**：
1. 安装 Duel Agents CLI
2. 配置两个不同的 API（如 GPT-4o vs Claude 4）
3. 输入辩论主题
4. 观看两个 AI 轮流反驳对方，最后用户打分
**风险/坑点**：实际结果可能比较水——AI 辩论容易变成"复读机"；需要两个 API Key（双倍费用）；辩论质量取决于 prompt 设计  
**推荐指数**：⭐⭐⭐⭐

### 选题 9：GitHub 项目热度日报——让你的 AI 智能维护 FILETREE

**工具/项目**：[filetree-skill](https://github.com/nekocode/filetree-skill)  
**本周热度**：⭐ 126  
**热门原因**：一个 Claude Code 插件，自动维护项目的 `FILETREE.md`。随着项目变大，文件结构经常改动，手写 README 里的目录树非常痛苦。这个 Skill 让 Agent 在每次提交时自动同步。  
**视频切入角度**：
- "让你的 AI 时时刻刻知道项目长什么样"——自动维护项目文件树
- 演示：项目变更后 Agent 自动更新 FILETREE.md
- 配合其他 Skill 展示"AI 项目管理"方案  
**目标观众**：使用 Claude Code/Codex 的开发者、技术创作者  
**可演示步骤**：
1. 安装 filetree-skill
2. 让 Agent 扫描项目，生成初始 FILETREE
3. 新增文件/目录，观察自动更新
4. 展示它如何帮助 Agent 理解项目结构
**风险/坑点**：功能单一，扩展性有限；只能用于 Claude Code 生态  
**推荐指数**：⭐⭐⭐
