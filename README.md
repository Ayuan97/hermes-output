# Hermes 输出仓库

> Hermes Agent 的输出仓库，用于持久化一切有价值的产出。

## 快速开始

- **找文档？** → 看 [文档索引](index.md)
- **了解仓库目的？** → 看 [仓库目的](purpose.md)
- **看全局概况？** → 看 [全局概览](overview.md)
- **写新文档？** → 看 [命名规范](SCHEMA.md)
- **看历史操作？** → 看 [操作日志](log.md)

## 目录结构

```
hermes-output/
├── README.md           # 本文件
├── SCHEMA.md           # 命名规范
├── purpose.md          # 仓库目的
├── index.md            # 文档索引
├── overview.md         # 全局概览
├── log.md              # 操作日志
├── 教程/               # 教程、操作指南
├── 笔记/               # 笔记、配置记录
├── 调研/               # 调研报告
├── 报告/               # 定期报告
├── 综合/               # 跨主题综合分析
├── 规划/               # 规划、路线图
├── 脚本/               # 脚本工具
├── 参考/               # 常用资料
└── 归档/               # 历史存档
```

## 命名规范

- 日期文档：`YYYY-MM-DD-中文标题.md`
- 纯知识文档：`中文标题.md`
- 专有名词保留英文：Hermes、GitLab、Claude 等

## 目录说明

| 目录 | 职责 | 内容类型 |
|------|------|----------|
| 教程/ | 可复现的操作流程 | 教程、指南 |
| 笔记/ | 配置变更、问题排查 | 笔记、备忘 |
| 调研/ | 有结论的深度分析 | 调研报告 |
| 报告/ | 定期生成的内容 | 日报、周报 |
| 综合/ | 跨主题综合分析 | 多源汇总 |
| 规划/ | 未来规划 | 路线图 |
| 脚本/ | 可执行工具 | Python 脚本 |
| 参考/ | 速查资料 | API 文档 |
| 归档/ | 过期内容 | 不再维护的资料 |
